# 🎭 「猜猜TA是谁」— 游戏设计方案 v1.0

> 核心理念：**一个名字，千种线索，万般乐趣**

---

## 一、游戏概述

| 项目 | 说明 |
|------|------|
| 游戏名称 | **猜猜TA是谁** |
| 类型 | 知识问答 / 社交对战 |
| 平台 | H5（优先）→ 微信小程序 → App |
| 核心玩法 | 根据系统或玩家给出的线索，猜出隐藏的人名 |
| 目标用户 | 15-40岁，喜欢知识竞赛、社交互动的用户 |

| 差异化 | AI 动态出题 × 三大玩法模式 × 深度社交 |

## 二、三大核心玩法模式

### 模式一：🔦 渐进揭秘（Progressive Reveal）

**设计理念**：像剥洋葱一样逐层揭露线索，越早猜对越厉害。

#### 基本规则
1. 系统选定一个目标人物，玩家看不到名字
2. 每轮揭露一条线索，最多 **8 条线索**
3. 玩家在任何时候都可以提交猜测
4. 第1条线索后猜对 = ⭐⭐⭐⭐⭐（满分），第8条才猜对 = ⭐（一星）

#### 线索层级设计（由模糊到精确）

```
第1条：时代/领域      → "这个人活跃在20世纪的科技领域"
第2条：国籍/地域      → "他出生在非洲"
第3条：职业特征       → "他的工作与无线通信有关"
第4条：成就/事件      → "他发明了一项改变世界的技术"
第5条：标志性细节     → "这项发明最初被认为是魔法"
第6条：人物关系       → "他和爱迪生有过著名的竞争"
第7条：名字首字母     → "他的姓氏以字母T开头"
第8条：致命线索       → "他的名字也是一个物理单位"
```

#### 趣味变体
| 变体 | 说明 |
|------|------|
| **计时模式** | 每条线索间隔10秒自动揭露，你必须在下一条出现前决定是否猜测 |
| **赌注模式** | 每次猜测消耗"猜测币"，猜错扣币，猜对按时机倍率返还 |
| **无尽模式** | 连续猜人，不休息，看你能坚持多少轮（类似Wordle的Streak） |

#### 计分公式
```
得分 = 基础分(100) × 线索系数(8→1递减) × 难度倍率 × 连击加成
线索系数：第1条猜对=8倍，第2条=7倍...第8条=1倍
难度倍率：普通=1x，困难=2x，地狱=3x
连击加成：连续猜对3个=1.2x，5个=1.5x，10个=2.0x
```

### 模式二：❓ 二十问（20 Questions）

**设计理念**：经典"20个问题"游戏，用策略性提问缩小范围。

#### 基本规则
1. 系统心中想好一个人，玩家不知道
2. 玩家每次提出一个是/否问题
3. 系统回答：**是 / 否 / 不适用**
4. 最多 **20 个问题**，之后必须提交最终猜测
5. 猜对即过关，剩余问题数越多奖励越高

#### 高效问题策略树（玩家脑中的博弈）

```
第一层（大分类）：
├── "这个人是虚构角色吗？"     → 缩小真实vs虚构
├── "这个人还在世吗？"         → 缩小时代范围
└── "这个人的职业和娱乐有关吗？" → 缩大领域

第二层（精确分类）：
├── 如果是娱乐 → "是音乐人吗？" → "是华语歌手吗？"
├── 如果是历史 → "是军事人物吗？" → "是中国古代的吗？"
└── 如果是虚构 → "是动漫角色吗？" → "是日本动漫吗？"

第三层（特征锁定）：
├── "这个人的名字是两个字吗？"
├── "这个人以反派形象著称吗？"
└── "这个人的标志性特征和红色有关吗？"
```

#### AI 回答引擎的关键
- 不能只回"是/否"，要带有**人格化反馈**：
  - "嗯...这个问题问得很聪明，答案是**否**。"
  - "你差点就踩到关键了！答案是**是**。"
  - "这个问题太宽泛了，但答案是**否**。我在想你是不是走偏了？"
- 偶尔给出**微表情/语气暗示**，让玩家觉得AI有"表情"

#### 趣味变体
| 变体 | 说明 |
|------|------|
| **倒计时问** | 每个问题限时15秒，超时算用掉一个 |
| **付费问题** | 有些问题要花金币才能问（如"名字首字母是？"） |
| **AI反问** | AI偶尔反问你"你觉得TA是哪个领域的？"来试探你的思路 |

### 模式三：🤝 描述接龙（Description Chain）

**设计理念**：社交性最强，用最少的词让别人猜中，考验表达和默契。

#### 基本规则
1. **出题方**选择一个人名，用 **3 个关键词** 描述
2. **猜题方**看到关键词后猜测
3. 猜错 → 出题方追加 **1 个关键词**，最多追加到 **7 个**
4. 每次追加关键词，猜题方都可以选择猜测
5. 越少关键词猜对，双方得分越高

#### 关键词规则
```
✅ 允许：特征词、事件词、关系词、隐喻词
   例："篮球"、"紫金"、"凌晨四点"

❌ 禁止：直接包含名字或名字的字
   例：猜"周杰伦"时不能用"周"、"杰"、"伦"

❌ 禁止：过于宽泛的词
   例："人"、"男"、"有名"（系统自动过滤）
```

#### 单人闯关中的描述接龙
- AI 出题，给你3个关键词，你来猜
- 你的目标：**3个词内猜对**
- AI 会根据你的历史表现动态调整关键词的"刁钻程度"

#### 趣味变体
| 变体 | 说明 |
|------|------|
| **emoji版** | 只能用emoji描述（🏀💜🌅 = 科比？）|
| **画图版** | 出题方画一幅简笔画，猜题方看图猜人 |
| **声音版** | 出题方录一段语音描述（模仿声音、说经典台词等）|

### 3.2 社交对战（Battle Mode）

#### 3.2.1 实时对战（1v1）

**模式A：竞速猜**
```
┌─────────────────────────────────┐
│         同一条线索同时展示         │
│                                   │
│   玩家A          vs         玩家B  │
│   ┌──────┐              ┌──────┐ │
│   │ 输入 │              │ 输入 │ │
│   │ 答案 │              │ 答案 │ │
│   └──────┘              └──────┘ │
│                                   │
│   谁先猜对谁得分，连对3个有combo    │
└─────────────────────────────────┘
```
- 两人同时看到同一条线索
- 每轮60秒，共5轮
- 猜对得分 + 速度加成
- 5轮结束后总分对比

**模式B：出题互坑**
```
第1回合：A给B出题 → B猜
第2回合：B给A出题 → A猜
...交替进行，共6回合（各出3题）

出题策略：
- 出太简单 → 对方秒猜，你得低分
- 出太难 → 对方猜不出，你也得低分
- 出得刚好 → 对方想一会儿才猜出，双方都高分
→ 最佳策略：出"中等偏难"的题
```

**模式C：默契挑战**
```
系统同时给A和B展示同一个描述
A和B各自写下自己认为描述的是谁
两人答案一致 → 双倍得分
两人答案不同 → 各自按自己答案计分

考验：你们的知识面是否重叠
```

#### 3.2.2 异步对战（好友挑战）

```
发起挑战 ──→ 生成挑战码/链接
                    │
          好友打开 ──→ 玩相同的题组
                    │
          结果对比 ──→ 生成对比卡
                    │
         分享到朋友圈/群聊
```

- 好友挑战卡包含：双方得分、用时、答对率、"谁更博学"的趣味评语
- 挑战记录永久保存，可以"复仇"

#### 3.2.3 大厅竞技（多人）

| 模式 | 人数 | 说明 |
|------|------|------|
| **淘汰赛** | 8人 | 每轮淘汰最低分，最后一人获胜 |
| **积分赛** | 4-8人 | 固定轮数，总分排名 |
| **主题房间** | 不限 | 房主设定主题（如"动漫专场"），自由加入 |
| **答题马拉松** | 无限 | 持续答题，随时加入/退出，实时排行榜 |

### 4.3 AI 动态出题引擎

传统静态题库的致命问题：**背完就废**。

解决方案：**AI 动态生成 + 静态题库混合**

```
                    ┌─────────────┐
                    │  题库选择器  │
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
        ┌──────────┐ ┌──────────┐ ┌──────────┐
        │ 静态题库  │ │ AI变体题 │ │ AI全新题 │
        │ (5000+)  │ │ (旧人新线索)│ │ (新人新线索)│
        │ 已验证   │ │ 每次不同  │ │ 需要审核  │
        └──────────┘ └──────────┘ └──────────┘

AI 动态生成流程：
1. 从人物池中选择（按难度+主题筛选）
2. AI 生成新的线索组合（不重复之前的线索措辞）
3. AI 生成新的关键词描述（3-7个不同角度）
4. 生成emoji描述变体
5. 质量检查 → 上线
```

### 8.3 答案验证策略（核心难点）

猜人名最大的技术挑战：**同一个名人有一百种叫法**

```python
# 答案验证优先级
def validate_answer(user_input: str, correct_answer: str, aliases: list[str]) -> bool:
    """
    验证策略（按优先级）：
    1. 精确匹配（去空格、统一大小写）
    2. 别名匹配（题库预设的别名列表）
    3. 模糊匹配（编辑距离 ≤ 2，处理错别字）
    4. 拼音匹配（中文同音字容错）
    5. AI语义匹配（最后兜底，用LLM判断"用户说的和正确答案是不是同一个人"）
    """
    normalized_input = normalize(user_input)

    # 精确匹配
    if normalized_input == normalize(correct_answer):
        return True

    # 别名匹配
    for alias in aliases:
        if normalized_input == normalize(alias):
            return True

    # 模糊匹配（Levenshtein距离）
    if levenshtein(normalized_input, normalize(correct_answer)) <= 2:
        return True

    # 拼音匹配
    if pinyin_match(normalized_input, correct_answer):
        return True

    # AI兜底（只在前4步都失败时调用，控制成本）
    return ai_semantic_match(user_input, correct_answer)
```

## 十一、竞品分析 & 差异化

| 竞品 | 优势 | 劣势 | 我们的差异化 |
|------|------|------|-------------|
| 猜画小歌(Google) | AI互动新颖 | 只有画画一种玩法 | 三种模式 × N种变体 |
| 头脑王者 | 社交对战成熟 | 题库固化，可背答案 | AI动态出题，无法背题 |
| 谁是卧底 | 社交性强 | 需要多人在线 | 单人也能玩三种模式 |
| Wordle | 极简设计，病毒传播 | 英文，单一玩法 | 中文，多模式+AI |

**核心竞争力总结**：
1. **AI驱动的无限题库** — 永远不会玩腻
2. **三种玩法自由切换** — 满足不同心情
3. **单人+社交双模式** — 一个人也能嗨，一群人更嗨
4. **渐进式难度曲线** — 新手友好，高手有挑战

## 十二、关键设计决策备忘

### 为什么选这三种模式？
- **渐进揭秘**：最低门槛，适合新手，爽感来自"少线索就猜中"
- **二十问**：策略深度最高，适合核心玩家，爽感来自"精准提问"
- **描述接龙**：社交性最强，适合朋友间玩，爽感来自"默契/搞笑"

### 最大的风险和对策
| 风险 | 对策 |
|------|------|
| AI生成的线索不准确 | 人工审核+用户反馈机制+社区纠错 |
| 题库被玩家背完 | AI动态出题，同一人物不同线索组合 |
| 对战模式作弊 | 客户端防篡改+服务端验证+答题时间异常检测 |
| 答案验证不准确 | 多层匹配策略+AI兜底+用户申诉 |
